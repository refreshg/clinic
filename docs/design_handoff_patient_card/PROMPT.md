# პრომპტი VS Code-ისთვის (Claude Code / Copilot / Cursor)

დააკოპირეთ ქვემოთ მოცემული ტექსტი და ჩააგდეთ ჩატში. წინასწარ პროექტის root-ში მოათავსეთ ეს საქაღალდე (`design_handoff_patient_card/`).

---

ააწყვე დენტალ კლინიკის პაციენტის ბარათის გვერდი ზუსტად იმ დიზაინით, რომელიც მოცემულია `design_handoff_patient_card/` საქაღალდეში:

1. ჯერ წაიკითხე `design_handoff_patient_card/README.md` — იქ არის სრული სპეციფიკაცია (განლაგება, ზომები, ფერები, ინტერაქციები, state).
2. `design_handoff_patient_card/reference-design.html` არის ვიზუალური რეფერენსი inline სტილებით — მას პიქსელ-ზუსტად უნდა დაემთხვეს შედეგი. ის HTML პროტოტიპია და არა production კოდი — ხელახლა ააწყვე ჩვენს სტეკზე.
3. ყველა ფერი, რადიუსი, ჩრდილი და ფონტი აიღე `design_handoff_patient_card/tokens.css`-დან — ნუ გამოიგონებ ახალ მნიშვნელობებს.

მოთხოვნები:
- სტეკი: [ჩაწერეთ თქვენი — მაგ. React + TypeScript + Tailwind / Vue / Odoo OWL]. თუ Tailwind-ს იყენებ, ტოკენები გადაიტანე theme-ის კონფიგში.
- ფონტები: Manrope + Noto Sans Georgian (Google Fonts).
- იკონები: lucide-react (ან lucide შესაბამისი პაკეტი), stroke 1.5 — რეფერენსის unicode გლიფების ნაცვლად.
- 4 ტაბი: ძირითადი, სამედიცინო, ფინანსური, ისტორია — ლოკალური state-ით.
- FDI კბილის სქემა ინტერაქტიული: ლეგენდაში ვირჩევ სტატუსს (კარიესი, დაბჟენილი, გვირგვინი, არხის მკურნალობა, იმპლანტი, არ არის, ამოსაღები, სხვა), კბილზე დაჭერით ენიჭება ეს სტატუსი და ფერი, ქვემოთ სიაში ჩნდება ჩანაწერი, სიიდან წაშლა შესაძლებელია. ნუმერაცია: ზედა რიგი 18–11 და 21–28, ქვედა 48–41 და 31–38.
- ყველა ჩექბოქსი და toggle-ბარათი ინტერაქტიული იყოს.
- მონაცემები გამოიტანე ცალკე ტიპიზებულ demo-ობიექტში (patient, contacts, allergies, procedures, documents, insurance), რომ მერე ადვილად ჩავანაცვლო API-თ.
- კომპონენტებად დაშალე: PatientHero, PillTabs, InfoCard/LabelValueGrid, CheckRow, ToothChart (ლეგენდა + ბადე + სია), StatCard, ProcedureRow, DocumentRow, ProgressStat.
- ეკრანი იყოს responsive: 1280px-ზე ორსვეტიანი ბადეები, ვიწროზე ერთ სვეტად ჩამოეწყოს; მინიმალური სამიზნე — ტაბლეტი (768px).

დაასრულე მთლიანად — ოთხივე ტაბის კონტენტით — და გაუშვი dev სერვერი, რომ შევამოწმო.

---

## რჩევა
თუ Claude Code-ს იყენებთ, პირველ ჯერზე უთხარით მხოლოდ სტეკის არჩევა და სტრუქტურის დაგეგმვა, მერე — იმპლემენტაცია ტაბ-ტაბ. სქრინშოტების დართვაც კარგი იდეაა (გახსენით reference-design.html ბრაუზერში და გადაუღეთ თითო ტაბს).

# Handoff: დენტალ კლინიკის პაციენტის ბარათი (Soft UI)

## მიმოხილვა
პაციენტის ბარათის ეკრანი დენტალური კლინიკის სისტემისთვის (Odoo-ს მონაცემთა სტრუქტურაზე დაფუძნებული). 4 ტაბი: **ძირითადი / სამედიცინო / ფინანსური / ისტორია**, ინტერაქტიული FDI კბილის სქემით.

## დიზაინ ფაილების შესახებ
`reference-design.html` არის **დიზაინ-რეფერენსი HTML-ში** — აჩვენებს ზუსტ ვიზუალს და ქცევას. ის **არ არის** production-კოდი: ამოცანაა ამ დიზაინის ხელახლა აწყობა თქვენი კოდბეისის გარემოში (React, Vue, Odoo QWeb/OWL და ა.შ.) მისი არსებული პატერნებით. თუ გარემო ჯერ არ არსებობს, აირჩიეთ შესაფერისი ფრეიმვორკი (რეკომენდაცია: React + Vite ან Next.js).

## სიზუსტე (Fidelity)
**High-fidelity** — ფერები, ტიპოგრაფია, დაშორებები, რადიუსები და ჩრდილები საბოლოოა. აღადგინეთ პიქსელ-ზუსტად. ყველა მნიშვნელობა `tokens.css`-შია.

## განლაგება
- გვერდის ფონი `--bg-page`; ცენტრში აპის კონტეინერი max-width 1280px, ფონი `--bg-app`, radius `--r-app`, ჩრდილი `--shadow-app`.
- **მარცხენა სვეტი**: ვერტიკალური pill (სიგანე 64px, ფონი `--primary`, radius 32px) იკონ-ღილაკებით 40×40, radius 14px; აქტიური — თეთრი ფონი, იასამნისფერი იკონა. იკონები: Lucide (bell, home/user, file-text, bar-chart, calendar, log-out), stroke 1.5-2.
- **მთავარი სვეტი** (padding 32px): top bar → hero ბარათი → pill ტაბები → ტაბის კონტენტი. ვერტიკალური gap 22px.

## ეკრანები / სექციები

### Top bar
მარცხნივ: მცირე ლეიბლი „დენტა კლინიკა" (12px, muted) + სათაური „პაციენტის ბარათი" (24px/800). მარჯვნივ: ძებნის pill (თეთრი, radius 999, ჩრდილი `--shadow-card`) და primary ღილაკი „+ ახალი ვიზიტი" (ფონი `--primary`, radius 999, ჩრდილი `--shadow-primary`).

### Hero პაციენტის ბარათი
ფონი `--primary-grad`, radius 28px, ჩრდილი `--shadow-hero`, თეთრი ტექსტი, padding 28×32.
- ავატარი 84×84, radius 26px, ფონი rgba(255,255,255,.18), ინიციალები 34px/800.
- სახელი 24px/800 + ჩიპები: „განმეორებითი" (ფონი `--pink`) და „P000002" (rgba(255,255,255,.16)), ორივე pill, 11px/700.
- მეტა-რიგი 13px, opacity .85: დაბადება/ასაკი, პირადი №, ტელეფონი, ელფოსტა; ქვემოთ 12px opacity .65: მისამართი, წყარო, რეგისტრაცია.
- მარჯვნივ ორი მაჩვენებელი: ლეიბლი 11px opacity .65 + მნიშვნელობა 22px/800 (დავალიანება ₾ 0.00, ბოლო ვიზიტი 3 ივლ).

### ტაბები
თეთრი pill-კონტეინერი (padding 6px, radius 999, ჩრდილი `--shadow-card`). ღილაკი: 13px/700, padding 10×22, radius 999. აქტიური: ფონი `--primary`, თეთრი ტექსტი, ჩრდილი; არააქტიური: გამჭვირვალე, ფერი `--text-muted`.

### ტაბი 1 — ძირითადი
- 2 სვეტი (1fr 1fr, gap 22): „ძირითადი ინფორმაცია" (label/value ბადე 180px+1fr; ლეიბლი muted, მნიშვნელობა 600; რიგებს შორის 1px `--row-line`) და „სტატუსი" — 5 ჩექბოქსი-რიგი (radius 14, მონიშნული რიგის ფონი `--bg-tint`; ჩექბოქსი 20×20 radius 7: მონიშნული `--primary` ფონი + თეთრი ✓ + ჩრდილი, ცარიელი — 2px `--border-input` ჩარჩო). ველები: სახელი ლათინურად, მოქალაქეობა, სქესი, მომართვის წყარო, მეურვე/მშობელი. სტატუსები: უცხოელი პაციენტი, პირველადი ვიზიტი, განმეორებითი პაციენტი ✓, მუდმივი პაციენტი, არასრულწლოვანი.
- „საკონტაქტო ინფორმაცია": ცხრივი ბადით (ძირით., ტელეფონი, კოდი, ტიპი, არხი, საგანგებო, ნათესაობა, წაშლა); პირველი (ძირითადი) რიგი გამოკვეთილია `--bg-soft` ფონით radius 14; „+ დამატება" ღილაკი — ჩიპ-სტილი (`--bg-chip` ფონი, `--primary` ტექსტი, pill).
- „შენიშვნა": textarea, ფონი `--bg-soft`, ჩარჩო 2px `--border-soft`, radius 16.

### ტაბი 2 — სამედიცინო
- 4 toggle-ბარათი რიგში (მწეველი, ალკოჰოლი, სისხლის შედედება, კარდიო რისკი): radius 20; ჩართული — თეთრი ფონი + ჩრდილი; გამორთული — rgba(255,255,255,.5).
- „ალერგიები და ანამნეზი" (1.2fr): ალერგიის გაფრთხილების ბლოკი — ფონი #fdf2f6, radius 16, ვარდისფერი "!" ბეჯი 34×34 radius 12; ქვემოთ label/value ბადე (ქრონიკული დაავადებები, მედიკამენტები, ოჯახური ანამნეზი).

## ინტერაქციები და ქცევა
- ტაბების გადართვა — ლოკალური state, ანიმაცია არაა სავალდებულო (სასურველია ფონის მდორე გადასვლა 150ms ease).
- ჩექბოქსები/toggle-ბარათები — click ცვლის boolean state-ს.
- FDI სქემა: ჯერ ლეგენდაში სტატუსის არჩევა (brush), შემდეგ კბილზე click → კბილს ენიჭება სტატუსი და ჩნდება სიაში; სიიდან ✕ შლის ჩანაწერს.
- Hover: ღილაკებზე ოდნავ მუქი ფონი; კბილებზე cursor:pointer + მსუბუქი scale(1.05) სასურველია.

## State
- `activeTab: 'main' | 'med' | 'fin' | 'hist'`
- `brush: ToothStatusId` (ნაგულისხმევი 'caries')
- `teeth: Record<FdiNumber, {status, note}>` (საწყისი: 18 healthy, 44 extract)
- `mainFlags`, `medFlags` — boolean map-ები
- მონაცემები (პაციენტი, კონტაქტები, პროცედურები) — API-დან; რეფერენსში hardcoded demo-მნიშვნელობებია.
